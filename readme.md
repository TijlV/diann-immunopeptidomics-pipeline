## Overview

This pipeline is designed for high-throughput immunopeptidomics analysis using data-independent acquisition (DIA) mass spectrometry. It uses DIA-NN's search capabilities while reducing computational complexity through peptide length-based library splitting and calibration-guided searching.

---

## Dependencies

- **[Nextflow](https://www.nextflow.io/docs/latest/install.html)** — workflow manager (see Nextflow docs for installation)
- **[Docker](https://www.docker.com/)** — required to run the DIA-NN container
- **DIA-NN Docker image** — [`paretje/diann:2.3.2`](https://hub.docker.com/r/paretje/diann)

Pull the Docker image with:

```bash
docker pull paretje/diann:2.3.2
```

## How It Works

The pipeline reduces the DIA-NN search space by splitting spectral libraries by peptide length. The workflow proceeds in three stages:

1. **Calibration search (`infinDIA`)** — A full-space search is performed to generate a calibration library, improving retention time and mass accuracy for downstream searches.
2. **Per-length searches** — Each peptide length subset is searched independently using the calibration library, parallelizing the workload.
3. **Match-between-runs (MBR)** — Results from all length-specific searches are merged and an MBR step is performed, maximizing identification depth and producing the final empirical output.

## Usage

### Setup

All key parameters are configured in `nextflow.config`:

| Parameter | Description |
|---|---|
| DIA files | Paths to your `.d`, `.raw`, or `.mzML` input files |
| FASTA file | Reference proteome for the database search |
| Library generation | Toggle to generate new libraries or reuse those from a previous run |
| Peptide lengths | Define which lengths to include in the split search |
| Additional settings | Other DIA-NN run parameters |

> **Note:** It is recommended to only use spectral libraries generated by this pipeline to ensure compatibility with the calibration and MBR steps.

To customize individual DIA-NN module settings beyond what is exposed in `nextflow.config`, edit the relevant process file in the `/modules` directory.

### Running the Pipeline

```bash
nextflow run main.nf
```

For additional run options (e.g. `-resume`, `-profile`, `-with-tower`), refer to the [Nextflow documentation](https://www.nextflow.io/docs/latest/index.html).

### Output Structure

```
Output/
├── empirical/          # Final DIA-NN output after match-between-runs
├── infinDIA/           # Results from the full-space calibration search
├── len8/               # Search results for peptides of length 8
├── len9/
├── len10/
├── len11/
├── len12/
└── libs/
    ├── empirical       # Empirical library used for the infinDIA search
    └── lengths/        # Per-length spectral libraries
```

The `empirical/` folder contains the primary output and is the recommended starting point for downstream analysis. The `len*/` and `infinDIA/` folders contain intermediate results and can be used for troubleshooting or re-running individual steps.
