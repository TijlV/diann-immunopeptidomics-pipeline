# DIA-NN Immunopeptidomics Pipeline

A [Nextflow](https://www.nextflow.io/) pipeline for analyzing DIA immunopeptidomics data using [DIA-NN](https://github.com/vdemichev/DiaNN). Supports `.d`, `.raw`, and `.mzML` input formats.

## Overview
This pipeline is designed for high-throughput immunopeptidomics analysis using data-independent acquisition (DIA) mass spectrometry. It uses DIA-NN's search capabilities and comes in two modes:

- **`length_split.nf`** — Full pipeline with peptide length-based library splitting and match-between-runs.
- **`empirical.nf`** — Streamlined pipeline using a single empirical spectral library.

## How It Works

### `length_split.nf` — Length-split pipeline
Reduces the DIA-NN search space by splitting spectral libraries by peptide length. The workflow proceeds in three stages:

1. **InfinDIA search** — A full-space search is performed to generate a calibration library, improving retention time and mass accuracy for downstream searches.
2. **Per-length searches** — Each peptide length subset is searched independently using the calibration library, parallelizing the workload.
3. **Match-between-runs (MBR)** — Results from all length-specific searches are merged and an MBR step is performed, maximizing identification depth.

### `empirical.nf` — Empirical library pipeline
A simplified single-library workflow intended for situations where a high-quality empirical spectral library already exists. The workflow proceeds in two stages:

1. **InfinDIA search** — A full-space search is performed to generate a calibration library, improving retention time and mass accuracy for downstream searches.
2. **Combined DIA-NN run** — A single DIA-NN run performs the first-pass search and MBR in one step using the empirical library, producing the final output directly.

## Usage

### Setup

All key parameters are configured in `nextflow.config`:

| Parameter | Description |
|---|---|
| DIA files | Paths to your `.d`, `.raw`, or `.mzML` input files |
| FASTA file | Reference proteome for the database search |
| Library generation | Toggle to generate new libraries or reuse those from a previous run |
| Peptide lengths | Define which lengths to include (`length_split.nf` only) |
| Empirical library | Path to an existing empirical spectral library |
| Additional settings | Other DIA-NN run parameters |

> **Note:** It is recommended to only use spectral libraries generated by this pipeline to ensure compatibility with the calibration and search steps.

To customize individual DIA-NN module settings beyond what is exposed in `nextflow.config`, edit the relevant process file in the `/modules` directory.

### Running the Pipeline

**Length-split pipeline** (full, parallelized by peptide length):

```bash
nextflow run length_split.nf
```

**Empirical pipeline** (streamlined, single empirical library):

```bash
nextflow run empirical.nf
```

For additional run options (e.g. `-resume`, `-profile`, `-with-report`), refer to the [Nextflow documentation](https://www.nextflow.io/docs/latest/index.html).

### Output Structure

#### `length_split.nf`

```
Output/
├── empirical/          # Final DIA-NN output after match-between-runs
├── infinDIA/           # Results from the infinDIA search
├── len8/               # Search results for peptides of length 8
├── len9/
├── len10/
├── len11/
├── len12/
└── libs/
    ├── empirical/      # Empirical library used for the infinDIA search
    └── lengths/        # Per-length spectral libraries
```

#### `empirical.nf`

```
Output/
├── empirical/          # Final DIA-NN output (first-pass + MBR combined)
├── infinDIA/           # Results from the infinDIA search
└── libs/
    └── empirical/      # Empirical library used for the infinDIA search
```

The `empirical/` folder contains the primary output and is the recommended starting point for downstream analysis. The `infinDIA/` folder contains intermediate results and can be used for troubleshooting or re-running individual steps.
